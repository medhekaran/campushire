# CampusHire
Job recruitment and campus hiring platform with Admin, Recruiter and Student roles.

## Tech Stack
Java, Spring Boot, Spring Data JPA, Hibernate, MySQL, Thymeleaf, Maven, HTML, CSS, JavaScript

## Features
- Registration and login with session management
- Recruiters post company drives
- Students create profiles and apply
- Admin dashboard

## How to Run
1. Create a MySQL database named campushire
2. Set the environment variable DB_PASSWORD
3. Run: mvn spring-boot:run
4. Open http://localhost:8080
